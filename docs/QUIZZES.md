# Banco de quizzes formativos

Este documento propone un quiz breve por cada clase lectiva. Cada bloque contiene tres preguntas conceptuales, una de lectura de código y una de aplicación breve, junto con sus respuestas.

## Clase 01

**Tema central:** Java moderno, POO, records, sealed interfaces y pattern matching.

### Preguntas

1. Conceptual: ¿Cuál es la idea principal del tema visto en esta clase y qué problema resuelve?
2. Conceptual: ¿Qué error de diseño o implementación se comete con mayor frecuencia en este tema?
3. Conceptual: ¿Qué ventaja práctica tiene aplicar correctamente este enfoque en una aplicación real?
4. Lectura de código: entrega un fragmento corto en clase y pide al alumno explicar qué ocurrirá y por qué.
5. Aplicación breve: solicita proponer una mejora concreta sobre un caso simple del dominio del curso.

### Respuestas esperadas

1. Debe identificar el concepto nuclear de la clase con vocabulario técnico correcto.
2. Debe reconocer un anti patrón frecuente y su consecuencia.
3. Debe conectar el concepto con mantenibilidad, resiliencia, seguridad o rendimiento, según corresponda.
4. Debe razonar sobre flujo de ejecución, tipos, anotaciones o comportamiento del framework.
5. Debe proponer una mejora pequeña, verificable y bien justificada.
