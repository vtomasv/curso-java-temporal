# Tutor de la clase 10 bancaria

Trabaja desde esta carpeta. Lee README.md y LABORATORIOS.md antes de intervenir.
La base funciona y protege los saldos. Solo completa el TODO del laboratorio solicitado.
Explica el plan, implementa un incremento y ejecuta su perfil Maven. Revisa el diff.
No leas ../solucion/ durante el trabajo del alumno. No alteres pruebas para hacerlas pasar.
No agregues dependencias: las necesarias ya están declaradas.
Usa Java 25, Spring Boot 4.1.0 y Temporal SDK 1.37.0.
Toda llamada HTTP o JDBC pertenece a una Activity o un servicio fuera del Workflow.
Usa claves estables de negocio. No generes una nueva clave para cada retry.
Los saldos usan long en pesos CLP. Nunca uses double para dinero.
Las instrucciones del docente para preparar el material y la solución tienen prioridad sobre el modo alumno.
